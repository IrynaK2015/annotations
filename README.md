Домашнє завдання "Анотації"

1. Створити анотацію, що приймає параметри методу. Написати код виклику анотованого методу із передаванням параметрів з анотації в метод, що викликається.

2. Написати клас TextContainer, який містить рядок. За допомогою механізму анотацій визначити:
  - в якому файлі має бути збережено текст
  - який метод виконує збереження.
Створити клас Saver, який збереже поле класу TextContainer у вказаному файлі.
